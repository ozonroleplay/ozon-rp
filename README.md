# 🚀 OZON RolePlay - Strona WWW Serwera FiveM

Profesjonalna, nowoczesna strona internetowa dla serwera **OZON RolePlay** z motywem neonowego fioletu, dopasowana do oficjalnego logo serwera.

---

## 🌟 Główne Funkcje

1. **Strona Główna (Hero Section)**:
   - Oficjalne neonowe logo OZON RolePlay
   - Przycisk szybkiego łączenia z serwerem przez konsolę F8 (`connect...`)
   - Bezpośrednie zaproszenie do Discorda (`https://discord.gg/ozonroleplay`)
   - Karta statusu serwera (Online / Tryb Hard-Medium RP / Społeczność)
2. **O Serwerze**:
   - Prezentacja atutów: optymalizacja, ekonomia, autorskie pojazdy, frakcje (LSPD, EMS, LSCM) i strefa przestępcza.
3. **Ekipa Serwera (Team)**:
   - Zarząd Główny, Developerzy, Moderacja i Support z badge'ami ról.
4. **Interaktywny Regulamin**:
   - Rozwijane karty akordeonowe (Zasady ogólne, PG, MG, RDM/VDM, FearRP, Voice Chat).
5. **System Ticketów (Pomoc)**:
   - Formularz zgłaszania problemów technicznych, skarg i pytań.
   - **Automatyczna wysyłka na Discorda przez Webhook** z estetycznym embedem.
6. **Formularz Podań do Administracji**:
   - Rekrutacja na Supporta, Moderatora, Opiekuna Frakcji itp.
   - Trafia bezpośrednio na prywatny kanał administracyjny na Twoim Discordzie.
7. **Panel Administratora z logowaniem Discord OAuth2**:
   - Przycisk autoryzacji Discord OAuth2 oraz tryb demonstracyjny.
   - Podgląd wszystkich nadesłanych ticketów i podań.
   - Zakładka szybkiej konfiguracji Discord Webhook (możesz wkleić link do webhooka bezpośrednio na stronie!).

## 🌐 Jak uruchomić stronę W 100% ZA DARMO?

Możesz wybrać jedną z dwóch najprostszych metod darmowego hostingu:

### Metoda 1: Vercel (Najszybsza – 2 minuty)
1. Załóż darmowe konto na [vercel.com](https://vercel.com).
2. Przeciągnij folder `ozon-rp-website` lub połącz ze swoim kontem GitHub.
3. Kliknij **Deploy**.
4. Twoja strona natychmiast działa pod darmowym adresem np. `ozon-roleplay.vercel.app` z darmowym certyfikatem SSL (kłódka HTTPS)!

### Metoda 2: GitHub Pages (0 zł na zawsze)
1. Załóż darmowe konto na [github.com](https://github.com).
2. Utwórz nowe repozytorium o nazwie np. `ozon-rp-website` (ustaw jako **Public**).
3. Wgraj pliki: `index.html`, `style.css`, `app.js`, `logo.png`.
4. Wejdź w repozytorium w **Settings** -> **Pages** -> pod **Branch** wybierz `main` i kliknij **Save**.
5. Po minucie Twoja strona będzie dostępna pod adresem: `twojanazwa.github.io/ozon-rp-website`.

## ⚙️ Jak podpiąć Webhook Discorda, żeby zgłoszenia lądowały na kanale?
1. Na swoim serwerze Discord wejdź w ustawienia kanału (np. `#tickety-logi` lub `#podania-rekrutacja`).
2. Kliknij **Integracje** -> **Webhooki** -> **Nowy Webhook**.
3. Kliknij **Kopiuj adres URL webhooka**.
4. Wejdź na swoją stronę do zakładki **Panel Admina** -> **Szybka Konfiguracja** -> wklej URL i kliknij **Zapisz Webhook**.
5. Gotowe! Każdy ticket i podanie wysłane ze strony natychmiast pojawi się na Twoim kanale Discord.
